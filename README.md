# DistriLac

Primera versión funcional del sistema para gestionar la distribuidora.

## Incluye
- Alta, búsqueda y eliminación de clientes.
- Alta, búsqueda y eliminación de productos.
- Asociación de producto con proveedor: Mauro / Nonna Pia, Casuarinas, Metti y FM.
- Carga de pedidos con selección de cliente, búsqueda de productos, cantidades y deuda anterior.
- Persistencia local en el navegador mediante `localStorage`.

## Objetivo siguiente
Cargar el catálogo real completo y la lista completa de clientes, luego sumar facturación, deudas, reportes y planificación de reparto.
